Proyecto 02

Experimentación gráfica

Este proyecto continúa explorando el código como una herramienta gráfica, utilizando formas y comportamientos que se construyen directamente desde la programación.

La propuesta busca observar cómo una composición puede variar y adquirir movimiento sin depender de una imagen completamente estática.
